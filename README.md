# Мебель на заказ Белгород · демонстрационный сайт

Персонализированная статическая демоверсия для предприятия ИП Курбанов Д. У., известного по VK `@mebelden_bel` и `@mebelryadom31`. **Это независимая концепция, не официальный сайт.**

## Структура

- `index.html` — главная; направления, проекты, производство
- `projects.html` — восемь кейсов из публикаций за ноябрь 2026 с фильтрами и подробными карточками
- `kitchens.html` — кухни
- `storage.html` — шкафы, прихожие и гостиные
- `materials.html` — фактуры, варианты фасадов, фурнитура из опубликованных работ
- `planner.html` — подбор мебели по размерам с несколькими помещениями, цветами, параметрами, фото и текстом заявки
- `contacts.html` — телефоны, сообщества VK, адрес производства, FAQ
- `assets/style.css`, `assets/app.js`, `assets/projects.json`, `assets/scenes/` — исходники и оригинальные SVG-иллюстрации
- `previews/` — скриншоты для просмотра и проверки
- `preview-offline.html` — самодостаточный автономный предпросмотр главной страницы (без требования локального сервера)

## Как посмотреть

Откройте `index.html` через браузер. Все ресурсы локальные. Альтернативный автономный предпросмотр: `preview-offline.html`. Для навигации по всем страницам лучше использовать простую локальную раздачу: `python -m http.server 8000` в папке проекта и затем `http://localhost:8000`.

## Публикация на Vercel

1. Распакуйте ZIP, загрузите содержимое в репозиторий GitHub.
2. В Vercel: Add New → Project → Import repository → Framework Preset `Other`.
3. Build Command пустой, Output Directory пустой, Root Directory на папке с `index.html`.
4. Deploy. Для демоверсии включены `noindex` и `robots.txt`.

## Функции

- Все страницы связаны навигацией, адаптивное меню на телефонах.
- Кнопки портфолио открывают подробную информацию, фильтры по типам мебели.
- Подборщик позволяет выбрать до 6 помещений, размеры, материал, цвет и элементы, динамически обновляет авторский SVG-эскиз, сохраняет черновик в localStorage.
- Можно прикрепить до 3 фотографий **только для локального просмотра** (они не отправляются и не сохраняются на сервере).
- Составляется текст заявки для копирования и ручной вставки в сообщения VK. Автоматической отправки, оплаты или подтверждения заказа нет.
